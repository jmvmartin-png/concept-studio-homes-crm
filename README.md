# Concept Studio Homes · CRM (v3)

App móvil (PWA) del CRM inmobiliario de **Concept Studio Homes**: captación de demanda y oferta, cruce automático con la cartera, avisos, inmuebles, clientes, pipeline de operaciones, visitas con parte firmado, documentación adjunta en todas las fichas y equipo (Jesús M.V. y Jesús Romero).

- **App:** https://jmvmartin-png.github.io/concept-studio-homes-crm/
- **Datos:** Supabase (Postgres + Auth + Storage privado, con RLS: solo los emails del equipo ven los datos).
- **Instalar en el móvil:** abrir la app en Chrome (Android) o Safari (iPhone) → *Añadir a pantalla de inicio*.

Especificación y prompt: [`docs/PROMPT_CRM_v3.md`](docs/PROMPT_CRM_v3.md).
